# 車型損益試算系統 — Apps Script 程式碼

個人使用版本（無登入權限控管、無情境鎖定、部門/科目可自由新增、圖表用 Google Charts）。
資料結構說明見 `../docs/data-schema.md`，架構說明見 `../docs/architecture.md`。

## 安裝步驟

1. 建立一個新的 Google Sheet（作為資料庫）。
2. 選單「擴充功能 → Apps Script」，開啟綁定的 Apps Script 專案。
3. 把本資料夾內所有檔案內容複製貼上到 Apps Script 編輯器（檔名需一致）：
   - `appsscript.json`（在編輯器左側「專案設定」勾選「顯示 appsscript.json」後才看得到）
   - `Code.gs` / `Constants.gs` / `Utils.gs` / `SetupSheets.gs` / `DataService.gs` / `CalcEngine.gs`
   - `index.html` / `style.html` / `script.html`
4. 在編輯器上方函式下拉選單選擇 `setupSpreadsheet`，按執行（首次執行會跳出授權視窗，同意即可）。
   執行後會在該 Google Sheet 自動建立所有分頁與標題列，並灌入固定的損益科目表。
5. 選單「部署 → 新增部署作業 → 網頁應用程式」：
   - 執行身份：我
   - 誰可以存取：僅限我自己
   - 部署後會得到一個網址，就是輸入/儀表板頁面。

## 使用順序

前端導覽以「車型」為最上層選單，「情境」是車型底下的次要選單（可在同一車型下並排比較
現況/目標/已知低減方向等多個情境版本）。

1. 「車型主檔」新增車型（如 `DA`、`DE`）—— 必須先有車型，才能往下建立車系。
2. 「車系設定」在上方選好車型後，新增該車型底下的車系（如 3人貨車 / 9人客貨車(商用) / 9人客貨車(接駁)）。
3. 「情境設定」在上方選好車型後，選 GATE 別（GATE F~A、Z）並自訂情境名稱。
   同一個 GATE 下可以有多個情境，例如「GATE F 現況」「GATE F 目標」。
4. 「銷售構成」輸入該情境下各車系的銷售構成比、預估月台數、LC年限、售價、廢車處理費(需標明含稅/未稅)。
   可用頁面上「依台數重算百分比」「依百分比反推台數」兩個按鈕，在台數與百分比間雙向換算。
   LIFE CYCLE 總台數 = 預估銷售台數(月) × 12 × LC年限，計算時自動代入，不需另外輸入。
5. 「銷貨成本」輸入成本明細（LP/KD 皆為成本項目，不區分採購模式）。外幣金額只要選幣別，
   系統會直接引用「匯率設定」頁的現況匯率換算，不需逐筆填匯率。
6. 「開發總投」輸入各部門投入金額；部門可自行輸入新名稱，每一列皆可獨立刪除；
   挑戰低減目標請直接輸入百分比數值（如 15 代表 15%）。資產類型決定攤提落點：
   模具→b5、設備→b8（銷貨成本），費用→f3/f4（車型專案開發費用），分母皆為 LIFE CYCLE 總台數。
7. 「營業費用」輸入 d/f1/h/J 科目金額。
8. 「科目設定」可自由新增/刪除銷貨成本與營業費用的明細科目；新增後會自動出現在對應頁面的下拉選單。
   結構科目(A/B/C/E/G/I/K)與自動計算科目不可刪除。
9. 「稅務費用比率」「匯率設定」分別輸入營業稅率/銷售佣金率/季Margin率/貨物稅率（皆輸入 0~100 的百分比數值），
   以及集團預算匯率/現況匯率（匯率不是比率，填原始數值）。
10. 切到「損益儀表板」加入比較欄位（車型 × 情境 × 車系或加權平均），按「重新計算」，
    即可跨車型／跨 GATE 並排比較損益表與圖表。

## 自動計算的科目（不需手動輸入，避免重複計列）

| 科目 | 來源 |
|---|---|
| P1~P8 售價結構（營業稅、銷售佣金、廠價...） | 銷售構成的售價欄位 + 稅務費用比率 |
| b5 模具費用 / b8 新增專屬設備 | 開發總投(模具/設備)低減後金額 ÷ LIFE CYCLE 總台數 |
| b13 貨物稅 | 廠價(未稅) × 貨物稅率 |
| d4 季Margin（原 0.5%Margin） | 實際零售價(未稅) × 季Margin率 |
| f3 / f4 車型專案開發費用 | 開發總投(費用類)低減後金額 ÷ LIFE CYCLE 總台數 |

## 已知簡化（相對於原始 Gate F Excel）

- 營業稅、銷售佣金、季Margin 用「稅務費用比率」設定的比率計算，未逐車系個別調整佣金級距；
  如需要特定車系不同費率，在該頁面加一列同 `ParamName`、選上對應「車系代號」覆寫全域值即可。
- 開發總投不再有 TNCAP 對應/不對應欄位；要比較有無 TNCAP 的差異，
  請在同一個 GATE 下開兩個情境（如「GATE F 對應TNCAP」「GATE F 不對應TNCAP」）並排比較。
- 沒有實作情境鎖定/核准流程、沒有登入權限分級（依你先前確認為個人使用，皆非必要）。
